# SOUL WRAPPED 2026 공개 투표

기존 화면과 후보 명단을 유지한 정적 웹페이지입니다. 누구나 로그인 없이 투표할 수 있습니다. 투표 시작 전 이름과 기수를 입력합니다. 투표는 Vercel 서버 함수를 거쳐 Google Sheet에 저장되고, 같은 이름·기수 조합의 재제출은 거부됩니다. **로그인이나 회원 명부 대조가 없으므로 타인 이름을 쓰거나 동명이인이 있는 경우에는 실제 사람별 1인 1표를 보장할 수 없습니다.**

각 투표 화면에서는 후보를 선택해야 다음 화면으로 갈 수 있습니다. 마지막 요약 화면의 **확정하기**를 누르면 투표를 저장하고, 저장에 성공한 경우에만 마지막 페이지로 이동합니다.

## 기존 배포를 업데이트할 때

1. Google 스프레드시트의 **확장 프로그램 → Apps Script**에서 기존 코드를 최신 [`apps-script.gs`](apps-script.gs)로 전부 교체하고 저장합니다. 스크립트 속성 `SPREADSHEET_ID`와 `VOTE_SHARED_SECRET`는 그대로 둡니다.
2. `setup()`을 다시 한 번 실행합니다. `응답_공개`의 B·C열에 이름·기수 열을 추가하고, 기존 브라우저 ID와 투표 기록은 오른쪽으로 이동해 유지합니다. `집계_공개` 득표수는 기존 기록까지 포함해 다시 계산합니다. 이전 기록에는 이름·기수가 없으므로 이 방식으로 소급 중복 확인은 할 수 없습니다. `setup()`은 반복 실행해도 열을 다시 삽입하지 않습니다.
3. Apps Script **배포 → 배포 관리 → 수정 → 새 버전**으로 웹 앱을 업데이트합니다. 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**여야 합니다. 아직 웹 앱을 배포하지 않았다면 새 배포를 만듭니다.
4. Vercel 프로젝트 환경 변수 `APPS_SCRIPT_URL`(Apps Script의 `/exec` 주소)과 `VOTE_SHARED_SECRET`(스크립트 속성과 동일한 값)을 유지합니다. `GOOGLE_CLIENT_ID`는 더 이상 필요 없으므로 제거할 수 있습니다. GitHub 변경이 Vercel에 배포되고 환경 변수 변경도 반영됐는지 확인합니다.
5. 사이트에서 이름·기수를 입력하고 전체 부문을 선택해 테스트 투표를 제출합니다. `응답_공개`에 한 행이 추가되고 `집계_공개`에 득표수가 표시되어야 합니다. 같은 이름·기수로 다시 제출하면 거부되어야 합니다. 테스트 응답을 삭제했다면 `rebuildTally()`를 실행해 집계를 동기화합니다.

## 투표 종료 후 식별 정보 삭제

이상 응답 확인을 마친 뒤 Apps Script에서 `closeVotingAndPurgeIdentifiers()`를 **한 번** 실행합니다. 이 함수는 새 투표를 차단하고 `응답_공개`의 이름, 기수, 이전 브라우저 ID를 삭제합니다. 투표 선택 결과와 집계는 남습니다. 실행 후에는 이름·기수를 복구할 수 없으므로 검토가 끝나기 전에는 실행하지 마세요. 다시 투표를 열 계획이라면 새 투표 기간과 중복 방지 기준을 먼저 정해야 합니다.

이름·기수는 식별 정보이므로 스프레드시트 공유 권한을 운영진으로 제한하세요. `응답_공개`라는 탭 이름은 공개 접근 권한을 뜻하지 않습니다.

제출 전에 사이트 주소 뒤에 `/api/connection`을 붙여 열어 보세요. `connected: true`면 Vercel이 최신 Apps Script와 통신하고 두 곳의 비밀키가 일치합니다. `connected: false`면 응답의 `reason`과 `scriptVersion`을 확인하세요. 이 확인 API는 비밀키 값을 반환하지 않습니다.

## 새로 설치할 때

- `VOTE_SHARED_SECRET`는 `openssl rand -hex 32`로 생성하고 Apps Script **프로젝트 설정 → 스크립트 속성** 및 Vercel **Secret** 환경 변수에 동일하게 입력합니다. GitHub에는 올리지 않습니다.
- Apps Script 속성 `SPREADSHEET_ID`에는 대상 시트 URL의 `/d/`와 `/edit` 사이 값을 입력합니다. `setup()`을 실행한 뒤 웹 앱으로 배포합니다.
- Vercel은 GitHub 저장소를 연결하고 프레임워크 **Other**, 출력 디렉터리 `public`을 사용합니다. 정적 페이지는 `public/index.html`, 서버 함수는 `api/vote.js`입니다.
- 화면이나 후보를 수정했다면 `soul-wrapped.src.html`을 고친 뒤 `python3 build.py`를 실행하고 생성된 `public/index.html`, `api/candidates.json`을 함께 커밋합니다.
